# Avans Robot Library

Control a Pololu Romi with a Raspberry Pi and Grove accessories using C#.
The library provides motors, LEDs, buttons, sensors, and display support.

- Start with the [general use guide](guide/index.md) for installation and examples.
- Browse the [API reference](api/Avans.StatisticalRobot.yml) for public types and methods, generated from the C# source and XML comments.
- Read [documentation setup](guide/documentation-setup.md) to build, publish, or maintain this site.

This site documents the current `master` branch. It can include changes that are
not yet available in the published NuGet package.
